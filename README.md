## AUEB - MSc in Data Science

Personal academic projects from the MSc in Data Science at the Athens University of Economics and Business.

### 1. Practical Data Science
Ancient Greek corpus annotation and century classification using Convolutional Neural Networks.

:bulb: Technologies used: ***Python (sklearn, Tensorflow)***

### 2. Machine Learning and Computational Statistics
Spectral unmixing classification using ML approaches.

:bulb: Technologies used: ***Python (sklearn)***

### 3. Timeseries Analysis and Forecasting
Timeseries and volatility forecasting using ARIMA and ARCH-type models.

:bulb: Technologies used: ***R***

### 4. Probability and Statistics for Data Analysis
Statistical inference using medical data.

:bulb: Technologies used: ***R***

### 5. Text Analytics and Engineering
Bi- and Tri-gram language models, and sentiment analysis through TF-IDF, Multi-Layer Perceptron and Transformer architecture.

:bulb: Technologies used: ***Python (sklearn, nltk, Tensorflow)***

### 6. Large Scale Linear Algebra
Least-Square optimization, Singular Value Decomposition and Pagerank applications.

:bulb: Technologies used: ***Python***

### 7. Large Scale Data Management
Data management in distributed systems through Spark and MonetDB.

:bulb: Technologies used: ***Python (PySpark), MonetDB***

### 8. Data Visualization and Communication
Visualization applications.

:bulb: Technologies used: ***R (ggplot)***

### 9. Deep Learning
Image classification through MNIST and Mura datasets.

:bulb: Technologies used: ***Python (sklearn, Tensorflow)***
